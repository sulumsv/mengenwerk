# Commit workflow

Kleine, in sich abgeschlossene Änderungen einzeln committen und pushen, statt sie zu größeren Commits zu bündeln.

Nach jedem Commit sofort einen PR auf main erstellen und mergen — nicht warten bis der Nutzer darum bittet. Commit-Message und PR-Titel sollen auf Deutsch beschreiben was die Änderung tut (nicht wie).
